# Simple Interest Calculator

A simple script/tool to calculate simple interest based on Principal, Rate of Interest, and Time period.

## Formula
$$\text{Simple Interest} = \frac{P \times R \times T}{100}$$

Where:
- **P** = Principal amount
- **R** = Annual interest rate (%)
- **T** = Time period (in years)

## Usage
Input the principal amount, interest rate, and time duration to compute the total interest earned or paid.
